# Global Job Market Analysis Dashboard
Global job market analysis using SQL, Excel and Power BI to explore job postings, salaries, employment types, remote work, experience levels and market trends.

## Project Overview

This project analyzes a global job postings dataset using Excel, SQL, and Power BI. The dashboard explores job postings across countries, companies, job titles, experience levels, employment types, remote work options, salaries, applicants, and posting trends over time.

## Tools Used

- **Excel** – Data cleaning and initial analysis
- **SQL** – Data querying and analysis
- **Power BI** – Data visualization and dashboard creation

- ## Key Analysis

- Job postings by country
- Top job titles and companies
- Employment type distribution
- Remote work distribution
- Experience level distribution
- Average salary by experience level
- Average applicants by experience level
- Job posting trends over time
